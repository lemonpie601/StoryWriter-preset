# 스토리 라이터 프리셋 개인 확장

이 ZIP은 **외부 개인 확장**입니다. 에이전트 설치 화면에 넣지 마세요. 기존 Story Writer를 교체하지 않습니다.

## 설치

1. Marinara 서버의 `.env`에 `ENABLE_EXTERNAL_EXTENSIONS=true`를 설정하고 서버를 다시 시작합니다.
2. 설정 → 고급 → Danger Zone에서 외부 확장 가져오기를 허용합니다.
3. 설정 → Addons → External Extensions에서 `story-writer-presets.zip`을 가져옵니다. 언어·버전에 따라 메뉴 이름은 다를 수 있습니다.
4. 코드와 **Full page access** 권한을 확인하고 해당 버전의 해시를 승인한 뒤 활성화합니다. 이 권한은 Marinara 페이지와 같은 출처의 API에 접근합니다.
5. Marinara 페이지를 새로고침하고 Home → Story Writer → 집필을 엽니다.

다른 기기에서 접속 중이면 기존 Marinara의 Admin Access 설정도 필요합니다. 이 확장은 외부 확장 허용이나 인증 설정을 자동 변경하지 않습니다.

## 사용

집필의 **프리셋**에서 기존 프리셋을 고르고 아래 변수 값을 설정합니다. 일반 단일 선택은 직접 고르거나 프리셋 기본값을 사용합니다. 토글·복수 선택·구분자·랜덤 선택도 지원합니다. 랜덤 단일 선택은 작품에 저장되고, 복수 랜덤은 챕터마다 선택한 후보 중 하나를 뽑습니다.

선택은 작품별 확장 저장소에 저장됩니다. 다른 작품으로 전환하면 그 작품의 설정이 표시됩니다. 작품 복제본은 새로 선택해야 합니다. 다른 기기에서 같은 작품의 확장 설정을 동시에 편집하지 마세요.

프리셋 사용 중 **문체 작가·서술 방식·기본 집필 프롬프트**를 모델 입력에서 제외합니다. 해당 입력란은 비활성화되며 기존 값을 지우지 않습니다. 사용 안 함으로 바꾸면 다시 사용할 수 있습니다.

## 지원 범위

- 프리셋 섹션 순서와 역할, 활성 그룹, XML·Markdown·없음 래핑, skipWrap, depth
- 캐릭터·페르소나·대사 예시·로어북 All/Before/After·대화 기록·대화 요약 마커
- 대화 기록은 챕터 요청/본문에, 대화 요약은 오래된 챕터 요약에 연결
- 프리셋 변수, 이름·필드 매크로, 지원되는 로컬 조건문과 요청 안의 setvar/getvar
- 다음 챕터, 빠른 답장, 이어쓰기, 재작성, 스트리밍, 중단

스토리 개요·노트·타임라인·언어·분량·금칙어·작가 메모는 유지합니다. 마커로 배치한 자료를 기본 시스템 문맥에 다시 넣지 않습니다. 프리셋 작성자가 일반 텍스트에 직접 반복해 적은 내용은 자동 삭제하지 않습니다.

**채팅 전용 메모리·에이전트 출력·ID 카드 삽입·서버 Decision·별도 채팅 상태가 필요한 매크로는 지원하지 않습니다.** 활성 상태로 발견하면 안내하고 해당 프리셋의 집필을 차단합니다. 필드 안에 중첩된 미지원 매크로도 검사하므로, 사용하지 않을 필드의 매크로를 정리해야 할 수 있습니다. 지원하지 않는 필드 필터·로어북 위치도 차단합니다.

프리셋의 **샘플링 Parameters와 Regex 연결은 적용하지 않습니다.** 모델과 생성 설정은 기존 Story Writer/Connection 설정을 사용합니다. strictRoleFormatting·singleUserMessage·assistant prefill을 요구하는 프리셋은 차단합니다. setvar 등으로 만든 임시 값은 한 집필 요청 안에서만 유지하며 다음 요청으로 저장하지 않습니다.

## 호환성 안내

공개 **Story Writer 0.2.0 staging 소스**를 기준으로 만들었으며, **0.1.1 원본 빌더**와도 다음 챕터·이어쓰기·재작성 요청 일치를 검증했습니다. Marinara Engine은 해당 Story Writer와 Full page access 개인 확장을 지원해야 합니다. 모든 버전이나 모든 프리셋의 호환성을 보장하지 않습니다.

저장된 작품 자료로 공식 빌더의 원래 요청을 재구성하고, 실제 요청과 정확히 일치할 때만 변환합니다. 저장 미완료, 삭제된 캐릭터, 변경된 패키지 구조, 다른 확장과의 충돌은 차단 사유가 될 수 있습니다. 프리셋을 끄면 원래 요청을 그대로 전달합니다. 요약·타임라인·수동 본문 편집은 프리셋으로 변환하지 않습니다.

## 문제가 생기면

- **마커가 필요합니다:** 프리셋 복사본에 대화 기록 마커를 추가합니다. 작품에서 캐릭터·페르소나·로어북을 선택했다면 해당 마커도 필요합니다. 로어북 All과 Before/After를 겹쳐 배치하지 마세요.
- **지원하지 않는 마커/매크로:** 프리셋 복사본에서 해당 기능을 끄거나 제거합니다. 같은 프리셋을 다시 선택하면 기본 변수 값으로 시작합니다.
- **요청과 저장 자료가 일치하지 않습니다:** 저장을 마치고 새로고침한 뒤 다시 시도합니다. 계속되면 프리셋을 끄세요.
- **작품 전환 확인 중:** 전환이 끝날 때까지 기다립니다. 오래 지속되면 페이지를 새로고침합니다.
- **설정 저장 실패:** 확장의 활성화·해시 승인·Admin Access를 확인합니다.
- **제거:** 외부 확장을 비활성화한 뒤 페이지를 새로고침합니다. 확장이 추가한 UI와 요청 변환을 종료합니다.

## 검증 범위

프롬프트 단위 검증 21개와 Chrome 브라우저 시나리오 2개를 통과했습니다. 추가로 사용자의 로컬 Marinara Engine 2.5.2 / Story Writer 0.1.1에서 별도 테스트 작품과 합성 프리셋을 만들고 실제 AI 생성을 확인했습니다. 단일 값 SOFT, 토글 꺼짐, 복수 A+B, 랜덤 후보 Y가 출력의 `TEST=SOFT||A + B|Y`로 반영됐습니다. 기존 작품의 본문은 수정하지 않았습니다.

1.0.1은 로컬 테스트에서 발견한 다른 확장의 `.swp-panel` CSS 충돌을 고쳤습니다. 이 확장의 UI는 고유한 `mspx` 이름을 사용합니다.

사용자의 FID MINI v1107-17은 활성 `agent_data` 마커가 있어 적용을 차단했습니다. 이 프리셋을 사용하려면 복사본에서 해당 마커를 끄세요. 임의로 다른 프리셋을 수정하지 않았습니다.

같이 제공하는 소스 ZIP에는 구현, 테스트, 빌드 스크립트와 원본 라이선스가 포함됩니다. 독립 제작 확장이며 Marinara 공식 배포물이 아닙니다.
